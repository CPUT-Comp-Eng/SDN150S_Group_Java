# 01 — Documentation

Design and reference documentation for the CryptoCoin application.

## Contents

| File             | Purpose                                               |
| ---------------- | ----------------------------------------------------- |
| `Pseudocode.md`  | Algorithm pseudocode for conversion and UI logic      |
| `Source Code.md` | Walkthrough of classes, methods, and design decisions |
| `Tool.md`        | Tools and technologies used in the project            |
| `UML diagram.md` | Contain the UML Diagram and Steps to recreate         |


## Conventions

- Markdown only — plain `.md` files, no proprietary formats.
- Keep diagram images (UML, ERD, flow) alongside these files if added separately,
  and reference them by relative path.
