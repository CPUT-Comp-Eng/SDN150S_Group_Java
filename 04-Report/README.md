## Editing
- Submit as `.pdf` unless the brief says otherwise — export from the `.docx`.
- Close the document in your editor before committing — LibreOffice/Word create
  `~$*.docx` and `.~lock.*#` temp files that are gitignored.
- Save the final version as `Report.docx` (and `Report.pdf` if exported).
